# Money - Expenses Tracker app 
Flutter mobile app with intuitive UI that helps user categorize expenses and get insights about spends analytically.

## Features
- User authentication 
- Login using Google account / Apple account
- Category wise expense management 
- Responsive UI
- Dark mode

## Tech Stack
- Flutter SDK: Flutter 3.27 • channel stable 
- Tools • Dart 3.4.3 • DevTools 2.34.3
- State Management: Flutter Bloc.
- Go router
- Firebase Auth
